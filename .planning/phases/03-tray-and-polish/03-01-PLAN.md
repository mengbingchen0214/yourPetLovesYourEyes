<task type="auto">
  <name>Task 1: Add system tray with Tauri's tray API</name>
  <files>src-tauri/src/tray.rs, src-tauri/src/main.rs, src-tauri/Cargo.toml</files>
  <action>
    1. Add `tauri-plugin-tray` to Cargo.toml (or use Tauri's built-in tray API — check Tauri 2.x docs for the current approach).

    2. Create `src-tauri/src/tray.rs` with:
       - `create_tray(app: &AppHandle) -> SystemTray` — creates a tray icon using the icon from `app.default_window_icon()` or a custom icon path
       - `build_menu(state: &AppState) -> SystemTrayMenu` — builds the menu dynamically based on current state

    3. The menu structure (matching the Electron version):
       - "显示宠物" → show pet window
       - "隐藏宠物" → hide pet window
       - separator
       - Countdown display (disabled label, e.g., "倒计时: 15:30")
       - separator
       - "暂停/继续" → pause or resume cycle
       - "屏幕遮罩: 开启/关闭" → toggle overlay
       - separator
       - "个性化" submenu:
         - "更换20分钟宠物照" → open file picker
         - "更换20秒宠物照" → open file picker
         - "更换顶部图标" → open file picker
         - "更换App图标" → open file picker
         - "修改问候语" → open text input dialog
       - separator
       - "☕ 支持开发者" → open donation dialog
       - separator
       - "Quit 退出" → quit app

    4. In `main.rs`, create the tray in the `setup()` hook:
       ```rust
       let tray = create_tray(&app_handle)?;
       app.handle().plugin(tray)?;
       ```

    5. Handle tray menu events in an event handler that matches menu item IDs to actions.

    What to avoid:
    - Don't use `tray.setTitle()` for countdown on macOS — Tauri's tray API may not support this directly. Instead, use `tray.set_tooltip()` to show the countdown in the tooltip, which works on all platforms.
    - Don't rebuild the menu on every click — update it when state changes.
    - Don't forget to handle the tray icon click (left-click should show the pet window).
  </action>
  <verify>`cargo tauri dev` launches. Tray icon appears. Right-click shows menu with all items. Clicking "显示宠物" shows the window.</verify>
  <done>System tray created. Menu shows all items. Basic show/hide works.</done>
</task>

<task type="auto">
  <name>Task 2: Implement countdown ticker</name>
  <files>src-tauri/src/tray.rs, src-tauri/src/state_machine.rs</files>
  <action>
    1. In the state machine, when entering Sleeping or Resting state, start a background tokio task that:
       - Every 1 second, calculates remaining time from `sleep_end_at` or `rest_end_at`
       - Formats as `MM:SS`
       - Updates the tray tooltip: `format!("护眼Pet  倒计时: {}", formatted)`
       - Updates the countdown menu item label

    2. When entering Paused state, stop the ticker and show "倒计时: 已暂停"

    3. When entering Greeting state, stop the ticker and show "倒计时: --:--"

    4. Use `app_handle.tray_by_id("main")` to get the tray handle and call `set_tooltip()` and `set_menu()`.

    What to avoid:
    - Don't update the tray from the main thread's event loop only — use a spawned tokio task with `app_handle` cloned into it
    - Don't forget to abort the ticker task when state changes — store the `JoinHandle` and abort it
    - Don't update more than once per second — 1s interval is enough
  </action>
  <verify>Tray tooltip shows countdown updating every second. Format is MM:SS. Paused shows "已暂停". Greeting shows "--:--".</verify>
  <done>Countdown ticker works. Updates every second. Correct format for all states.</done>
</task>

<task type="auto">
  <name>Task 3: Wire tray actions to state machine</name>
  <files>src-tauri/src/tray.rs, src-tauri/src/main.rs</files>
  <action>
    Connect all tray menu actions to the state machine:

    1. "暂停/继续" → if Sleeping/Resting, call `pause_cycle()`. If Paused, call `resume_cycle()`.
    2. "屏幕遮罩" → toggle `overlay_enabled` in AppState. If overlay is now disabled, hide overlays. If enabled and currently Resting, show overlays.
    3. "显示宠物" → `window.show()` + `window.set_focus()`
    4. "隐藏宠物" → `window.hide()`
    5. "Quit 退出" → cleanup (destroy overlays, stop timers) + `app_handle.exit(0)`

    For each action, emit the appropriate Tauri event so the frontend updates its UI.

    What to avoid:
    - Don't call `app.quit()` directly — use `app_handle.exit(0)` after cleanup
    - Don't forget to emit `overlay-toggle` event when overlay is toggled from tray
  </action>
  <verify>All tray actions work: pause/resume, overlay toggle, show/hide, quit. Frontend updates match tray state.</verify>
  <done>All tray actions wired to state machine. Events flow correctly.</done>
</task>
