<task type="auto">
  <name>Task 1: Fix macOS-specific issues</name>
  <files>src-tauri/src/*.rs, src-tauri/tauri.conf.json</files>
  <action>
    Common macOS issues and fixes:

    1. **Window transparency not working**: Ensure `tauri.conf.json` has `"transparent": true` AND the window background is set to transparent in CSS (`background: transparent` on body).

    2. **Always-on-top not working**: Use `window.set_always_on_top(true)` in Rust after window creation, in addition to the config setting.

    3. **Dock icon**: Tauri apps show a dock icon by default. To hide it (like EyePet), set in `tauri.conf.json`:
       ```json
       "macOSPrivateApi": true
       ```
       And in Rust: `app.set_activation_policy(tauri::ActivationPolicy::Accessory)` — this hides the dock icon and makes it a menu-bar-only app.

    4. **Overlay on all workspaces**: Use `window.set_visible_on_all_workspaces(true)` for overlay windows.

    5. **Tray icon not showing**: Ensure the icon file exists at the path specified in `tauri.conf.json`. Tauri on macOS requires a template image (18x18 or 22x22 PNG).

    Test each fix by running `cargo tauri dev`.

    What to avoid:
    - Don't use `NSWindow` APIs directly — use Tauri's abstraction
    - Don't forget to test on both Apple Silicon and Intel if possible
  </action>
  <verify>All macOS issues fixed. App behaves identically to the Electron version.</verify>
  <done>macOS-specific issues resolved. App works correctly on macOS.</done>
</task>

<task type="auto">
  <name>Task 2: Fix Windows-specific issues</name>
  <files>src-tauri/src/*.rs, src-tauri/tauri.conf.json</files>
  <action>
    Common Windows issues and fixes:

    1. **Window transparency**: Tauri on Windows uses WebView2. Transparency should work but may require the `"transparent": true` config AND the CSS `background: transparent`. If it doesn't work, try setting the window color to `#00000000` (fully transparent).

    2. **Taskbar visibility**: `skip_taskbar: true` in config should prevent the app from showing in the taskbar. If not, use `window.set_skip_taskbar(true)` in Rust.

    3. **Tray icon**: Windows tray icons should be `.ico` format. Ensure the icon path in `tauri.conf.json` points to a valid `.ico` file.

    4. **File paths**: Windows uses backslashes. Use `std::path::PathBuf` for all file operations — never hardcode `/` or `\`.

    5. **DPI scaling**: Windows may scale the window. Use `window.set_size(LogicalSize::new(200, 260))` with `LogicalSize` (not `PhysicalSize`) to handle DPI scaling correctly.

    6. **Overlay windows**: On Windows, overlay windows may not be click-through by default. Use `window.set_ignore_mouse_events(true)`.

    Test each fix by building on Windows or downloading the GitHub Actions artifact.

    What to avoid:
    - Don't assume macOS behavior on Windows — test everything
    - Don't use Unix-specific APIs (e.g., `std::os::unix`)
    - Don't hardcode paths — always use `PathBuf`
  </action>
  <verify>All Windows issues fixed. App behaves identically to the Electron version.</verify>
  <done>Windows-specific issues resolved. App works correctly on Windows.</done>
</task>

    2. Update the version in `tauri.conf.json`:
       ```json

       ```

    3. Commit all changes:
       ```bash
       git add -A
       git commit -m "feat: migrate from Electron to Tauri (v2.0.0)"
       ```

    4. Tag the release:
       ```bash
       git tag v2.0.0
       git push origin v2.0.0
       ```

    5. GitHub Actions will automatically build and create a release.

    6. Download the artifacts and do a final verification on each platform.

    What to avoid:
    - Don't forget to update both Cargo.toml AND tauri.conf.json versions
    - Don't tag before all tests pass
    - Don't delete the old Electron code from git history — it's fine to keep it
  </action>
