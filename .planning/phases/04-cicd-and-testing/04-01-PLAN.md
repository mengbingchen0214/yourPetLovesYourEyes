<task type="auto">
  <name>Task 1: Create Tauri GitHub Actions workflow</name>
  <files>.github/workflows/release.yml</files>
  <action>
    Replace the existing `.github/workflows/release.yml` with a Tauri-based workflow:

    ```yaml
    name: Release

    on:
      push:
        tags:
          - 'v*'
      workflow_dispatch:

    permissions:
      contents: write

    jobs:
      build:
        strategy:
          fail-fast: false
          matrix:
            include:
              - platform: macos-latest
                args: '--target aarch64-apple-darwin'
              - platform: macos-latest
                args: '--target x86_64-apple-darwin'
              - platform: windows-latest
                args: ''
              - platform: ubuntu-22.04
                args: ''

        runs-on: ${{ matrix.platform }}

        steps:
          - uses: actions/checkout@v4

          - name: Setup Node.js
            uses: actions/setup-node@v4
            with:
              node-version: 22

          - name: Install Rust
            uses: dtolnay/rust-toolchain@stable
            with:
              targets: ${{ matrix.platform == 'macos-latest' && 'aarch64-apple-darwin,x86_64-apple-darwin' || '' }}

          - name: Install dependencies (Ubuntu only)
            if: matrix.platform == 'ubuntu-22.04'
            run: |
              sudo apt-get update
              sudo apt-get install -y libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf

          - name: Build Tauri app
            uses: tauri-apps/tauri-action@v0
            env:
              GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
              TAURI_SIGNING_PRIVATE_KEY: ${{ secrets.TAURI_SIGNING_PRIVATE_KEY }}
            with:
              tagName: v__VERSION__
              releaseName: 'EyePet v__VERSION__'
              releaseBody: 'See the assets to download this version.'
              releaseDraft: false
              prerelease: false
              args: ${{ matrix.args }}
    ```

    Key differences from the old workflow:
    - Single job with matrix strategy (vs. 3 separate jobs)
    - Uses `tauri-apps/tauri-action` (vs. manual `pnpm install` + `electron-builder`)
    - No pnpm needed — Tauri builds with Cargo
    - Rust toolchain setup is handled by `dtolnay/rust-toolchain`
    - Linux dependencies are installed in a single step
    - The action handles artifact upload and GitHub release creation

    What to avoid:
    - Don't keep the old electron-builder workflow — replace it entirely
    - Don't forget the `TAURI_SIGNING_PRIVATE_KEY` secret — the build will fail without it
    - Don't add `pnpm install` — there's no Node.js build step anymore (frontend is static HTML)
    - Don't forget the Ubuntu dependencies — Tauri needs `webkit2gtk` on Linux
  </action>
    <verify>Workflow file is valid YAML. Push a test tag to trigger the build. All 4 matrix jobs start.</verify>
    <done>GitHub Actions workflow created. Builds trigger on tag push. Matrix covers macOS (arm64+x64), Windows, Linux.</done>
</task>

<task type="auto">
  <name>Task 2: Set up Tauri signing key and GitHub secret</name>
  <files>src-tauri/tauri.conf.json</files>
  <action>
    1. Generate the Tauri signing key pair:
       ```bash
       cargo tauri signer generate
       ```
       This outputs a private key and public key.

    2. Add the public key to `tauri.conf.json`:
       ```json
       "updater": {
         "pubkey": "dW50cnVzdGVkIGNvbW1lbnQ6..."
       }
       ```

    3. Add the private key as a GitHub Secret:
       - Go to GitHub repo → Settings → Secrets → Actions
       - Add `TAURI_SIGNING_PRIVATE_KEY` with the private key value

    4. Verify the key is correctly configured by running:
       ```bash
       cargo tauri signer sign -k "$TAURI_SIGNING_PRIVATE_KEY" -f src-tauri/target/release/bundle/macos/EyePet.app
       ```

    What to avoid:
    - Don't commit the private key to the repo — only the public key goes in tauri.conf.json
    - Don't lose the private key — you need it to sign all future updates
    - Don't use the same key for different apps — generate a unique key for EyePet
  </action>
  <verify>`cargo tauri signer generate` produces a key pair. Public key is in tauri.conf.json. Private key is in GitHub Secrets.</verify>
  <done>Signing key generated. Public key in config. Private key in GitHub Secrets.</done>
</task>
