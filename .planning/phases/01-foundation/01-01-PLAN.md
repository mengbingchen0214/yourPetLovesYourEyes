<task type="auto">
  <name>Task 1: Install Tauri CLI and scaffold src-tauri</name>
  <files>src-tauri/Cargo.toml, src-tauri/tauri.conf.json, src-tauri/src/main.rs, src-tauri/capabilities/default.json, src-tauri/icons/</files>
  <action>
    1. Install Rust toolchain if not present: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`
    2. Install Tauri CLI: `cargo install tauri-cli --version "^2.0.0"`
    3. From the project root, run: `cargo tauri init --force`
       - App name: `EyePet`
       - Identifier: `com.eyepet.app`
       - Frontend path: `..` (since we're in src-tauri/)
       - Dev server URL: leave blank (we'll use static files)
    4. This creates src-tauri/ with Cargo.toml, tauri.conf.json, src/main.rs, capabilities/, icons/
    5. Copy icon files from build/ into src-tauri/icons/:
       - build/icon.icns → src-tauri/icons/icon.icns (macOS)
       - build/icon.png → src-tauri/icons/icon.png (Linux)
       - For Windows .ico: convert icon.png to icon.ico (use `convert` from ImageMagick or an online tool)
    6. Verify `cargo tauri build` compiles (this will take a few minutes first time)

    What to avoid:
    - Don't run `tauri init` without `--force` — it will fail if src-tauri already exists
    - Don't change the app identifier from `com.eyepet.app` — it must match the existing electron-builder config for auto-updater continuity
  </action>
  <verify>`cargo tauri build` completes without errors. A binary is produced in src-tauri/target/release/.</verify>
  <done>Tauri project builds successfully. src-tauri/ directory exists with Cargo.toml, tauri.conf.json, src/main.rs, capabilities/, and icons/.</done>
</task>

<task type="auto">
  <name>Task 2: Configure tauri.conf.json for EyePet's window needs</name>
  <files>src-tauri/tauri.conf.json</files>
  <action>
    Edit tauri.conf.json to match EyePet's requirements:

    1. Set `"frontendDist": "../"` — Tauri will serve static files from the project root (where index.html lives)
    2. Set `"app": { "withGlobalTaui": true }` for Tauri's JS API
    3. Configure the main window in `"app.windows"`:
       - title: "EyePet"
       - width: 200, height: 260
       - decorations: false (borderless)
       - transparent: true
       - alwaysOnTop: true
       - resizable: false
       - skipTaskbar: true
       - visible: false (we'll show it programmatically after setup)
    4. Set `"bundle": { "active": true, "targets": "all", "icon": [...] }` with the icon paths
    5. Set `"identifier": "com.eyepet.app"` to match existing app

    What to avoid:
    - Don't set `"devServer"` — we're using static files, not a dev server
    - Don't enable `"security": { "csp": ... }` yet — we need inline scripts for the existing frontend
  </action>
  <verify>`cargo tauri dev` launches a window. Window is borderless, transparent, and always-on-top. No console errors.</verify>
  <done>tauri.conf.json configured. App launches with correct window properties.</done>
</task>

<task type="auto">
  <name>Task 3: Set up Cargo.toml with required Tauri plugins</name>
  <files>src-tauri/Cargo.toml</files>
  <action>
    Edit Cargo.toml to add these dependencies:

    ```toml
    [dependencies]
    tauri = { version = "2", features = [] }
    tauri-plugin-shell = "2"        # For opening external links (donation URL)
    tauri-plugin-dialog = "2"       # For file picker dialogs (image selection)
    tauri-plugin-updater = "2"      # For auto-updater (replaces electron-updater)
    tauri-plugin-single-instance = "2"  # Prevent multiple instances
    serde = { version = "1", features = ["derive"] }
    serde_json = "1"
    tokio = { version = "1", features = ["time"] }  # For async timers
    ```

    Then run `cargo build` to download and compile dependencies.

    What to avoid:
    - Don't add `tauri-plugin-notification` — we use system tray, not notifications
    - Don't add `tauri-plugin-fs` yet — Tauri has built-in fs capabilities
    - Don't add `tauri-plugin-process` — not needed for this app
  </action>
  <verify>`cargo build` completes without errors. All dependencies resolve.</verify>
  <done>Cargo.toml has all required dependencies. Build succeeds.</done>
</task>
